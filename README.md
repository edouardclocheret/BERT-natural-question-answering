# Bert based question answering model

This repository contains a question answering model by Edouard Clocheret.

## Requirements: 
json version: 2.0.9
torch version: 2.6.0.dev20241112
transformers version: 4.47.0
tqdm version: 4.67.1
matplotlib version: 3.9.3
sklearn version: 1.6.0
